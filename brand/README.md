# Fleetdock — final logo kit

Approved modular F concept, redrawn as clean vector geometry.

## Files
- svg/fleetdock-logo-light.svg — turquoise mark and dark wordmark; light backgrounds.
- svg/fleetdock-logo-dark.svg — turquoise mark and light wordmark; dark backgrounds.
- svg/fleetdock-logo-black.svg and fleetdock-logo-white.svg — monochrome.
- svg/fleetdock-mark*.svg — standalone transparent marks.
- svg/fleetdock-app-icon.svg — square app/avatar icon on a dark background.
- png/ — transparent PNG exports; wordmarks 2048 px wide, marks 1024 px.
- favicon/ — SVG, multiresolution ICO, and PNG at 16, 32, 48, 180, 192, 512 px.
- Fleetdock_Final_Preview.png — light and dark presentation.

## Colors
Turquoise #2DD4BF · Charcoal #101820 · Off-white #F5F7FA

## Typography
Wordmark based on Inter Bold, optical size 32, converted to vector paths.
No font installation or external font request is needed to display the SVGs.

## Usage
Preserve proportions. Leave at least one spine-width of clear space around the mark.
Use the app icon/favicon at small sizes. For the horizontal wordmark, use at least
140 px display width; below this, prefer the standalone mark.
Do not add gradients, shadows, outlines, rotation, or stretch the artwork.

## Web
Copy favicon files to your public directory and add:
```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="apple-touch-icon" href="/icon-180.png">
```
Keep transparent logo files on backgrounds with sufficient contrast.
All SVG text is outlined; the mark remains editable as separate path elements.
